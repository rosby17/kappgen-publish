Mettre à jour

Relance simplement la même commande (ou renvoie le même message à Claude). La nouvelle version remplace l'ancienne et KappGen Publish se recharge tout seul dans Chrome en moins d'une minute. Aucun clic à refaire : tes réglages, ton abonnement et ce qui a déjà été publié sont conservés.

Installer à la main (sans commande)

📦 Je préfère télécharger le fichier moi-même
  1. Télécharge le fichier : kappgen-uploader.zip
  2. Dans Téléchargements, double-clique sur le .zip : un dossier kappgen-uploader apparaît.Dans Téléchargements, clic droit sur le .zip → « Extraire tout… » → « Extraire ». Range ce dossier dans tes Documents et ne le supprime plus.
  3. Dans Chrome, tape chrome://extensions dans la barre d'adresse, puis Entrée.
  4. Allume « Mode développeur » → « Charger l'extension non empaquetée » → choisis le dossier kappgen-uploader (clique une seule fois dessus) → « Sélectionner ».

Pour une mise à jour à la main : remplace le dossier par le nouveau, puis clique ↻ sur la carte KappGen Publish.

Ça ne marche pas ?

Pourquoi Claude ne peut pas faire les 3 clics à ma place ?

C'est une protection de Google Chrome : une extension qui ne vient pas de la boutique de Chrome ne peut être ajoutée que par la personne devant l'écran. Ça empêche les logiciels malveillants d'installer des extensions en cachette. Claude fait tout le reste.

Je ne trouve pas le bouton « Charger l'extension non empaquetée »

Le Mode développeur n'est pas allumé : regarde tout en haut à droite de la page des extensions et clique sur l'interrupteur pour qu'il soit bleu.

Chrome dit « Fichier manifeste manquant ou illisible »

Le mauvais dossier a été choisi. Relance la commande (elle recopie le bon chemin), puis refais le clic 3 en collant le chemin.

Le Terminal dit « command not found » ou PowerShell affiche une erreur rouge

La commande a été mal copiée. Utilise le bouton « Copier la commande » plutôt que de la sélectionner à la main, puis colle-la en entier. Sur Windows, ouvre bien PowerShell (pas « Invite de commandes »).

Au démarrage, Chrome affiche « Désactiver les extensions en mode développeur »

C'est un simple rappel de Chrome. Clique sur la croix pour le fermer, ne clique pas sur « Désactiver ».

Rien n'est publié
  1. Chrome doit rester ouvert (KappGen regarde ton dossier toutes les 5 minutes).
  2. Tu dois être connecté à ta chaîne YouTube dans ce même Chrome.
  3. Chaque vidéo doit avoir son fichier texte (titre + description) dans son dossier.
  4. Les vidéos déjà présentes avant que tu choisisses le dossier attendent un clic sur « Publier maintenant » : seules les nouvelles partent toutes seules.
Est-ce que c'est sûr ?

Oui. Le code est public sur GitHub, y compris celui de la commande d'installation (Mac, Windows). KappGen Publish lit uniquement le dossier que tu choisis et n'envoie tes vidéos qu'à YouTube, Facebook ou TikTok, depuis ton propre navigateur. Aucun mot de passe ne lui est donné.
