1Télécharger le fichier

Ouvre cette page dans Google Chrome (pas Safari, pas Edge, pas Firefox), puis clique sur le gros bouton bleu « Télécharger KappGen Publish » en haut de la page.

Le fichier kappgen-uploader.zip arrive dans ton dossier Téléchargements.

💡 Pas de Chrome sur ton ordinateur ? Installe-le d'abord, gratuitement : google.com/chrome.

2Le décompresser et le ranger

Un fichier .zip est une boîte fermée : il faut l'ouvrir pour sortir le dossier qu'il contient.

  1. Ouvre le Finder, puis le dossier Téléchargements.
  2. Double-clique sur kappgen-uploader.zip. Un dossier kappgen-uploader apparaît juste à côté.
  3. Glisse ce dossier kappgen-uploader dans ton dossier Documents.

3Ouvrir la page des extensions de Chrome

Dans Chrome, clique dans la barre d'adresse (là où tu tapes les sites web), colle cette adresse et appuie sur Entrée :

chrome://extensions

Pour des raisons de sécurité, Chrome n'autorise pas les liens vers cette page : il faut la copier-coller (ou la taper).

4Activer le « Mode développeur »

En haut à droite de cette page, clique sur l'interrupteur « Mode développeur » pour qu'il devienne bleu. Une ligne de boutons apparaît alors en haut.

💡 Le nom fait peur, mais c'est simplement l'option qui permet d'installer une extension venant d'un fichier, et pas de la boutique de Chrome. Ça ne change rien d'autre à ton navigateur.

5Installer KappGen Publish

  1. Clique sur « Charger l'extension non empaquetée » (le premier bouton qui vient d'apparaître).
  2. Une fenêtre s'ouvre : va dans Documents, clique une seule fois sur le dossier kappgen-uploader pour le sélectionner (sans entrer dedans).
  3. Clique sur « Sélectionner » (Mac) ou « Sélectionner un dossier » (Windows).

7Se connecter et faire les réglages

  1. Connecte-toi avec ton compte KappGen (bouton « Se connecter avec Google »). Pas encore de compte ? Crée-le gratuitement sur app.kappgen.com.
  2. Commence ton essai gratuit de 3 jours, ou choisis une formule : 2 $ par mois, 20 $ par an ou 50 $ à vie (carte, PayPal ou Mobile Money). Tout se débloque tout seul dès le paiement confirmé.
  3. Ouvre Réglages et choisis le dossier de tes vidéos (celui où tu ranges tes vidéos finies), puis clique « Autoriser à chaque visite ».
  4. Colle le lien de ta chaîne YouTube et de tes autres pages (Facebook, TikTok…).

Mettre à jour vers une nouvelle version

  1. Télécharge à nouveau le fichier avec le bouton de téléchargement et décompresse-le (étape 2).
  2. Remplace l'ancien dossier kappgen-uploader de tes Documents par le nouveau (même nom, même endroit).
  3. Ouvre chrome://extensions et clique sur la flèche ↻ de la carte KappGen Publish.
Tes réglages, ton abonnement et la liste de ce qui a déjà été publié sont conservés.

Ça ne marche pas ?

Je ne trouve pas le bouton « Charger l'extension non empaquetée »

Le Mode développeur n'est pas activé : regarde tout en haut à droite de la page chrome://extensions et clique sur l'interrupteur pour qu'il soit bleu (étape 4).

Chrome dit « Fichier manifeste manquant ou illisible »

Tu as choisi le mauvais dossier. Il faut choisir le dossier kappgen-uploader décompressé (pas le fichier .zip, et pas un dossier à l'intérieur). Recommence l'étape 5 et clique une seule fois sur kappgen-uploader avant « Sélectionner ».

Au démarrage, Chrome affiche « Désactiver les extensions en mode développeur »

C'est un simple rappel de Chrome pour les extensions installées depuis un fichier. Clique sur la croix pour le fermer, ne clique pas sur « Désactiver ».

L'extension a disparu ou affiche une erreur

Le dossier kappgen-uploader a sans doute été supprimé ou déplacé. Remets-le dans tes Documents (ou retélécharge-le), puis sur chrome://extensions clique ↻ sur sa carte ; si elle n'y est plus, refais l'étape 5.

Rien n'est publié
  1. Chrome doit rester ouvert (KappGen regarde ton dossier toutes les 5 minutes).
  2. Tu dois être connecté à ta chaîne YouTube dans ce même Chrome.
  3. Chaque vidéo doit avoir son fichier texte (titre + description) dans son dossier.
  4. Les vidéos qui étaient déjà dans le dossier avant que tu le choisisses attendent un clic sur « Publier maintenant » : seules les nouvelles partent toutes seules.
Est-ce que c'est sûr ?

Oui. Le code est public sur GitHub. KappGen Publish lit uniquement le dossier que tu choisis et n'envoie tes vidéos qu'à YouTube, Facebook ou TikTok, depuis ton propre navigateur. Aucun mot de passe ne lui est donné. Détails : politique de confidentialité.

J'ai plusieurs chaînes YouTube

Utilise un profil Chrome par chaîne (menu Chrome → Profils → Ajouter), connecté au bon compte YouTube. Installe KappGen Publish dans chaque profil (étapes 3 à 7) avec le dossier de vidéos de cette chaîne.
