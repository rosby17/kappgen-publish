Le panneau de KappGen Publish te guide ensuite étape par étape.

  4. Les Réglages s'ouvrent : choisis le dossier de tes vidéos et colle le lien de ta chaîne YouTube (et de tes autres pages).

Ça ne marche pas ?

Les questions qui reviennent le plus souvent.

Pourquoi Claude ne peut pas faire les 3 clics à ma place ?

C'est une protection de Google Chrome : une extension qui ne vient pas de la boutique de Chrome ne peut être ajoutée que par la personne devant l'écran. Ça empêche les logiciels malveillants d'installer des extensions en cachette. Claude fait tout le reste.

Je ne trouve pas « Charger l'extension non empaquetée »

Le Mode développeur n'est pas allumé : regarde tout en haut à droite de la page des extensions et clique sur l'interrupteur pour qu'il soit bleu.

Chrome dit « Fichier manifeste manquant ou illisible »

Le mauvais dossier a été choisi. Il faut le dossier kappgen-uploader lui-même (pas le .zip, pas un dossier à l'intérieur). Relance la commande, puis refais le clic 3 en collant le chemin.

Le Terminal dit « command not found » ou PowerShell affiche une erreur rouge

La commande a été mal copiée. Utilise le bouton « Copier la commande » plutôt que de la sélectionner à la main, puis colle-la en entier. Sur Windows, ouvre bien PowerShell (pas « Invite de commandes »).

Chrome affiche « Désactiver les extensions en mode développeur »

C'est un simple rappel de Chrome au démarrage. Clique sur la croix pour le fermer, ne clique pas sur « Désactiver ».

Rien n'est publié
  1. Chrome doit rester ouvert : KappGen regarde ton dossier toutes les 5 minutes.
  2. Tu dois être connecté à ta chaîne YouTube dans ce même Chrome.
  3. Chaque vidéo doit avoir son fichier texte (titre + description) dans son dossier.
  4. Les vidéos présentes avant le choix du dossier attendent un clic sur « Publier maintenant » : seules les nouvelles partent toutes seules.
J'ai plusieurs chaînes YouTube

Utilise un profil Chrome par chaîne (menu Chrome → Profils → Ajouter), connecté au bon compte YouTube. Dans chaque profil, ouvre la page des extensions et refais les 3 clics (le chemin à coller est le même).

L'extension a disparu ou affiche une erreur

Le dossier kappgen-uploader a sans doute été supprimé ou déplacé. Relance la commande (ou retélécharge le fichier), puis clique ↻ sur sa carte dans chrome://extensions ; si elle n'y est plus, refais les 3 clics.
